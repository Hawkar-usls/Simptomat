# Simptomat
### Legacy conversational health-information prototype

`experimental` · `non-diagnostic` · `not a medical device`

This repository is retained as a historical software prototype for conversational health-information workflows.

It must **not** be interpreted as a diagnostic system, treatment recommendation engine, emergency-triage service or clinically validated medical device.

## Use boundary

Any health-related output from this code or from a connected language model is informational/experimental only. Real medical decisions require appropriate qualified clinical evaluation; urgent or emergency situations should use the relevant local emergency-care pathway rather than this repository.

The repository is not part of the account's flagship research portfolio. Current research work is indexed in the account's [machine-readable portfolio](https://github.com/Hawkar-usls/Janus/blob/main/portfolio-index.json).
